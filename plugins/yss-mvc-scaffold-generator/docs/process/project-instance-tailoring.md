# 项目实例流程覆盖

本目录是 `project-instance` 的项目级流程说明，优先于模板源仓库的默认示例。

## 阶段

1. 需求与数据契约：确认需求文档、表结构 MD、权限范围和验收场景。
2. 规格冻结：冻结分析主题、查询/结果契约和必要 API。
3. 垂直切片实现：端到端交付一个可验证分析能力。
4. 自动门禁：编译、单元测试、SQL 只读校验、MD 一致性、Oracle 集成测试。
5. 发布确认：自动门禁通过后只保留一次人工确认。
6. 运行监控：监控慢查询、失败率、资源配额和审计记录。

## 裁剪规则

默认不单独执行 Discovery、产品原型、架构评审、测试评审和发布评审。以下变更必须追加专项审查：权限模型、Oracle 数据源、DDL/迁移、跨库访问、查询资源阈值和回滚策略。
