# MVC 环境维护记录

本轮为 L3 模板维护：generation-semantics、cross-repo-contract、aggregate-behavior-change。源码在基座 MVC skill；插件是受管分发副本。DDD 和前端基座技能不修改。

环境恢复只写相邻 skillUtils；不使用项目初始化函数覆盖代码、POM、业务词汇、Spec 或 Ticket。首次安装与升级使用 staging，失败恢复旧目录。旧工具包没有 MVC 完整性基线时保留现场并报告迁移；在新父目录 clone 项目后可恢复缺失环境。

环境有效技能、Registry、各平台投影与锁信息由同一生成器生成。版本由维护者统一管理，日常检查只读，升级显式执行。首次安装采用发行资产；后续比较全部文件与发行内容。哈希是完整性与一致性证据，不等于签名或发行来源认证。

验证范围包含新建回归、已有非空项目恢复、干运行不落盘、重复执行、本地漂移、失败清理、MVC 路由与平台投影。机械生成不使用 Java 业务 TDD；以 Node 行为场景验证生成和恢复合同。未改 Java/POM 模板，不因本轮环境工具改动重新下载 Maven 业务依赖。

正式发布另按基座完整模板门禁执行。本记录不表示 release-ready，实际命令和结果见维护验证证据。
